# supabase — the database (empty until Phase 3)

This folder will hold the database's table definitions and its security rules (Row Level Security: each customer can only reach their own websites and files).

Supabase itself runs on Supabase's servers, not in this project. These files are the written record of how it is set up, so the setup can be reviewed and repeated.

Phase 1 uses mock data only, so this folder is a placeholder.
